# 🎓 Companion University

## 📜 Executive Summary
An educational platform built on the "Reading Companion" and "Personal Library." The user sets a learning plan (e.g., learn programming), and the Companion generates the curriculum, tracks progress, gives exercises, and reminds the user of review times. This transforms the Companion into a **complete personal university**.

## 🎯 Why This Matters
Because learning is a never-ending journey. And the Companion University makes the Companion your guide on this journey.

## 📊 Core Features
| Feature | Description |
| :--- | :--- |
| **Learning Plans** | Generate a full curriculum upon your request. |
| **Progress Tracking** | Follow your progress step by step. |
| **Exercises & Reviews** | Custom exercises and review reminders. |
| **Absolute Privacy** | All progress is stored locally. |

## 💎 Connection to the Ecosystem
The Companion University is the "greatest teacher." It lets "The Companion" lead you from ignorance to knowledge.
