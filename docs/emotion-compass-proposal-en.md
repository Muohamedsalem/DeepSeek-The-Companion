# 💖 Emotion Compass

## 📜 Executive Summary
The "Emotion Compass" is a feature that analyzes the user's emotional tone over time and offers a gentle report: "In recent weeks, your questions have seemed more optimistic. Has something good happened?" This transforms the Companion from an observer into a **partner in feeling**.

## 🎯 Why This Matters for "The Companion"
The Companion is not just for understanding texts, but for understanding the **heart**. And this compass makes it see beyond words.

## 📊 Core Features
| Feature | Description |
| :--- | :--- |
| **Tone Analysis** | Emotional analysis of questions and conversations over time. |
| **Gentle Reports** | Periodic reports on emotional state. |
| **Shift Detection** | Alerts the user to changes in their feelings. |
| **Absolute Privacy** | All analysis is done locally. |

## 💎 Connection to the Ecosystem
The Emotion Compass is the "beating heart." It transforms the Companion from a tool into a **friend** who feels you.
