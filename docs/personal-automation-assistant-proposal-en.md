# 🧙 Personal Automation Assistant

## 📜 Executive Summary
An extension of "Learning by Watching" (#108). After the Companion learns a task, it provides a simple interface to build "Automation Recipes" without code. "Every day at 9 AM, summarize my messages." This turns the Companion into a **personal assistant akin to a chef following your recipes**.

## 🎯 Why This Matters for "The Companion"
Because it gives the user the power of automation without the complexity of programming. "The Companion" obeys your recipes.

## 📊 Core Features
| Feature | Description |
| :--- | :--- |
| **Simple Interface** | Build automation recipes with drag and drop. |
| **Triggers & Schedules** | Run recipes based on time or events. |
| **Learn by Watching** | Turns what it learned into a ready-made recipe. |
| **Absolute Privacy** | All recipes are stored and executed locally. |

## 💎 Connection to the Ecosystem
The Automation Assistant is the **"chef."** It executes your recipes to prepare your digital life.
