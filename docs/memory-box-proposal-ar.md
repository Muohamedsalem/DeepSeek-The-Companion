# 🗃️ صندوق الذكريات (Memory Box)

## 📜 خلاصة تنفيذية
"صندوق الذكريات" هو ميزة تسمح للمستخدم بوضع علامة على أجزاء محددة من المحادثات كـ "ذكريات خالدة". هذه الذكريات لا تُمحى أبدًا، وتُعرض في واجهة جميلة تشبه ألبوم الصور، مع إمكانية البحث فيها.

## 🎯 لماذا هذا مهم لـ "الرفيق"؟
رؤيتنا لـ "الرفيق" هي أن يكون "بيتًا زجاجيًا تملكه". هذا البيت يحتاج إلى ركن خاص، يضم أثمن اللحظات التي عاشها المستخدم مع رفيقه. ليس كل سطر في المحادثة قابلًا للنسيان، وبعضها يستحق أن يبقى إلى الأبد.

## 📊 الميزات الأساسية
| الميزة | الوصف |
| :--- | :--- |
| **وضع علامة** | يستطيع المستخدم تحديد أي جزء من المحادثة وحفظه كذكرى. |
| **واجهة الألبوم** | تُعرض الذكريات في واجهة بصرية جذابة، مع إمكانية التمرير والتصفح. |
| **بحث دلالي** | يمكن البحث داخل الذكريات باستخدام كلمات مفتاحية. |
| **حماية من الحذف** | الذكريات المحفوظة لا تُمحى عند مسح المحادثة الأصلية. |

## 💎 الصلة بنظام "الرفيق"
صندوق الذكريات هو الوجه العاطفي لـ "بروتوكول الإنعاش". بينما يستعيد البروتوكول السياق، يستعيد صندوق الذكريات **الروح**.
