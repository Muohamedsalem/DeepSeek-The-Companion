# ⌨️ اختبارات التدقيق اللغوي للوحة المفاتيح العربية

## 📜 خلاصة تنفيذية
هذا المقترح يهدف إلى تصميم حالات اختبار شاملة للوحة المفاتيح العربية الافتراضية، لضمان أنها تتعامل مع كل حروف العربية وعلامات التشكيل بشكل صحيح.

## 🎯 لماذا هذا مهم لـ "الرفيق"؟
لوحة المفاتيح العربية هي "المفتاح" الذي يضمن ألا يُغلق باب "الرفيق" في وجه أي مستخدم عربي. لكن المفتاح يجب أن يكون دقيقًا. حرف واحد مفقود، أو همزة لم تُكتب، كفيل بأن يجعل التجربة ناقصة.

## 📊 حالات الاختبار المقترحة
| الحالة | الوصف |
| :--- | :--- |
| **الحروف الأساسية** | اختبار كل حروف الأبجدية العربية (28 حرفًا). |
| **الألف المقصورة والياء** | التأكد من التمييز بين الألف المقصورة (ى) والياء (ي). |
| **الهمزات** | اختبار الهمزة على الألف (أ)، على الواو (ؤ)، على الياء (ئ)، وعلى السطر (ء). |
| **التاء المربوطة والمفتوحة** | التأكد من التمييز بين التاء المربوطة (ة) والمفتوحة (ت). |
| **علامات التشكيل** | اختبار الفتحة (َ)، الضمة (ُ)، الكسرة (ِ)، السكون (ْ)، الشدة (ّ). |
| **الحروف المركبة** | اختبار لا (لأ)، لا (لإ)، لا (لآ). |

## 💎 الصلة بنظام "الرفيق"
هذا الاختبار هو الدرع الذي يحمي "المفتاح". بدون هذه الاختبارات، قد يكون المفتاح معطوبًا، وقد لا نعرف.
