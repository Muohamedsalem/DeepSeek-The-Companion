# 💡 Idea Lab
## 📜 Executive Summary
The "Idea Lab" is a creative space inside "The Companion" that helps you generate new ideas. It can apply techniques like reverse brainstorming, lateral thinking, or the SCAMPER method. The Companion doesn't just discuss your ideas, it helps you **produce** new ones.

## 🎯 Why This Matters for "The Companion"
The Companion is not just a mirror that reflects, but a **factory** that produces. And this lab transforms creativity from a waiting state into a methodical process.

## 📊 Core Features
| Feature | Description |
| :--- | :--- |
| **Creative Techniques** | Apply brainstorming, lateral thinking, SCAMPER. |
| **Idea Generation** | Produce new ideas based on your input. |
| **Idea Organization** | Categorize and save ideas for later reference. |
| **Absolute Privacy** | All ideas are stored locally. |

## 💎 Connection to the Ecosystem
The Idea Lab is the "factory." It transforms the Companion from a listener into a **producer**.
