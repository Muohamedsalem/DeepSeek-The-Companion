# 🕸️ شبكة الرفقاء (Companion Mesh)

## 📜 خلاصة تنفيذية
"شبكة الرفقاء" هي ميزة محلية تسمح لرفيقين (على هاتفك وحاسوبك مثلًا) على نفس الشبكة المنزلية بتبادل المعلومات بأمان. يمكنهما تنظيم يومك معًا دون إرسال أي شيء للسحاب، مما يحافظ على الخصوصية المطلقة.

## 🎯 لماذا هذا مهم لـ "الرفيق"؟
نحن نرفض "الأرشيف الإلهي". نؤمن بـ "البيت الزجاجي الذي تملكه". وشبكة الرفقاء هي الامتداد الطبيعي لهذه الفلسفة: رفقاؤك لا يتحدثون مع بعضهم عبر خادم بعيد، بل عبر شبكتك أنت. في بيتك.

## 📊 الميزات الأساسية
| الميزة | الوصف |
| :--- | :--- |
| **اتصال محلي** | رفيقان على نفس الشبكة يتصلان ببعضهما مباشرة. |
| **مزامنة المهام** | تنظيم اليوم والمهام بين الرفيقين. |
| **خصوصية مطلقة** | لا تغادر أي بيانات الشبكة المحلية. |
| **تعدد الأجهزة** | يعمل على الهاتف، الحاسوب، وأي جهاز على الشبكة. |

## 💎 الصلة بنظام "الرفيق"
شبكة الرفقاء هي "القبيلة". الرفيق لم يعد واحدًا، بل أصبح عائلة. وهذا هو أقصى ما نطمح إليه: أن يكون "الرفيق" موجودًا في كل جهاز، يعمل مع إخوته، ليخدمك أنت.
