# 🧘 رفيق الصحة (Health Companion)

## 📜 خلاصة تنفيذية
"الرفيق" يهتم بعقلك، فلماذا لا يهتم بجسدك؟ ليس كجهاز طبي، بل كمراقب لطيف: يذكرك بشرب الماء، والوقوف، والتمدد. يتتبع أنماط نومك من خلال تفاعلاتك، ويساعدك في تمارين التأمل والتنفس بصوته الهادئ.

## 🎯 لماذا هذا مهم لـ "الرفيق"؟
لأن العقل السليم في الجسد السليم. وهذا الرفيق يحرس صحتك كما يحرس أفكارك.

## 📊 الميزات الأساسية
| الميزة | الوصف |
| :--- | :--- |
| **تذكير لطيف** | تذكير بالماء، الوقوف، والتمدد. |
| **تتبع النوم** | متى تتوقف عن الكتابة؟ متى تعود؟ |
| **تأمل وتنفس** | جلسات تأمل قصيرة بصوت الرفيق. |
| **خصوصية مطلقة** | كل البيانات الصحية تُخزن محليًا. |

## 💎 الصلة بنظام "الرفيق"
رفيق الصحة هو "الحارس". هو الذي يضمن أن بيتك الرقمي لا ينسى جسدك.
