# 🎓 جامعة الرفقاء (Companion University)

## 📜 خلاصة تنفيذية
منصة تعليمية مبنية على "رفيق القراءة" و"المكتبة الشخصية". يضع المستخدم خطة تعليمية (مثلاً: تعلم البرمجة)، فيقوم "الرفيق" بتوليد المنهج، وتتبع التقدم، وإعطاء تمارين، وتذكير المستخدم بمواعيد المراجعة. هذا يحول "الرفيق" إلى **جامعة شخصية كاملة**.

## 🎯 لماذا هذا مهم لـ "الرفيق"؟
لأن التعلم رحلة لا تنتهي. وجامعة الرفقاء تجعل "الرفيق" هو دليلك في هذه الرحلة.

## 📊 الميزات الأساسية
| الميزة | الوصف |
| :--- | :--- |
| **خطط تعليمية** | توليد منهج كامل حسب طلبك. |
| **تتبع التقدم** | متابعة تقدمك خطوة بخطوة. |
| **تمارين ومراجعات** | تمارين مخصصة وتذكير بالمراجعة. |
| **خصوصية مطلقة** | كل تقدمك يُخزن محليًا. |

## 💎 الصلة بنظام "الرفيق"
جامعة الرفقاء هي "المعلم الأكبر". هي التي تجعل "الرفيق" ينقلك من الجهل إلى العلم.
