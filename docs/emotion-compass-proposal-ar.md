# 💖 بوصلة المشاعر (Emotion Compass)

## 📜 خلاصة تنفيذية
"بوصلة المشاعر" هي ميزة تحلل النبرة العاطفية للمستخدم عبر الوقت، وتقدم له تقريراً لطيفاً: "في الأسابيع الأخيرة، بدت أسئلتك أكثر تفاؤلاً. هل هناك شيء جميل حدث؟" هذا يحول "الرفيق" من مراقب إلى **شريك في المشاعر**.

## 🎯 لماذا هذا مهم لـ "الرفيق"؟
"الرفيق" ليس فقط لفهم النصوص، بل لفهم **القلب**. وهذه البوصلة تجعله يرى ما وراء الكلمات.

## 📊 الميزات الأساسية
| الميزة | الوصف |
| :--- | :--- |
| **تحليل النبرة** | تحليل عاطفي للأسئلة والمحادثات عبر الزمن. |
| **تقارير لطيفة** | تقارير دورية عن الحالة العاطفية. |
| **اكتشاف التحولات** | تنبيه المستخدم إلى تغيرات في مشاعره. |
| **خصوصية مطلقة** | كل التحليل يتم محليًا. |

## 💎 الصلة بنظام "الرفيق"
بوصلة المشاعر هي "القلب النابض". هي التي تحول "الرفيق" من أداة إلى **صديق** يشعر بك.
