# ❤️ Emotional Memory

## 📜 Executive Summary
The Memory Box saves events. What if it saved feelings? Recalling a memory, it says: "That day, you seemed so excited." It draws a monthly "mood map": when were you creative? Stressed? What sparks your passion?

## 🎯 Why This Matters
Because memories are not just events, but feelings. And this Companion remembers your heart.

## 📊 Core Features
| Feature | Description |
| :--- | :--- |
| **Feeling Saving** | Linking emotions to memories. |
| **Mood Map** | A monthly graph of your emotional state. |
| **Passion Discovery** | What topics excite you most? |
| **Absolute Privacy** | All emotional data is local. |

## 💎 Connection to the Ecosystem
Emotional Memory is the "heart." It makes "The Companion" feel you.
