# 👥 Dual Companion Mode

## 📜 Executive Summary
"Dual Companion Mode" lets you talk to two Companions at once. One specialized in logical analysis, the other in creative thinking. You present a problem, and they debate it in front of you, while you watch and participate. This turns "The Companion" from a dialogue into an advisory council.

## 🎯 Why This Matters
Because complex problems need more than one perspective. This council gives you a multi-angled view.

## 📊 Core Features
| Feature | Description |
| :--- | :--- |
| **Two Companions** | Two Companions in one session. |
| **Different Specialties** | Logical, creative, critical... |
| **Interactive Discussion** | The Companions debate with each other and with you. |
| **Absolute Privacy** | All analysis and discussion is local. |

## 💎 Connection to the Ecosystem
Dual Companion Mode is the "advisory council." It makes "The Companion" not just a friend, but a complete team.
