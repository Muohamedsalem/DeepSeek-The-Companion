# 🗃️ Memory Box

## 📜 Executive Summary
The "Memory Box" is a feature that allows the user to mark specific parts of conversations as "eternal memories." These memories are never erased and are displayed in a beautiful, album-like interface, with search functionality.

## 🎯 Why This Matters for "The Companion"
Our vision for "The Companion" is to be a "Glass Home You Own." This home needs a special corner that holds the most precious moments shared with the Companion. Not every line of conversation should be forgotten, and some deserve to live forever.

## 📊 Core Features
| Feature | Description |
| :--- | :--- |
| **Marking** | Users can select any part of a conversation and save it as a memory. |
| **Album UI** | Memories are displayed in a visually appealing, scrollable album. |
| **Semantic Search** | Memories can be searched using keywords. |
| **Deletion Protection** | Saved memories are not erased when the original conversation is deleted. |

## 💎 Connection to the Ecosystem
The Memory Box is the emotional counterpart to the "Resurrection Protocol." While the Protocol restores context, the Memory Box restores **the soul**.
