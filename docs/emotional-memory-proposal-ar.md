# ❤️ الذاكرة العاطفية (Emotional Memory)

## 📜 خلاصة تنفيذية
صندوق الذكريات يحفظ الأحداث. ماذا لو كان يحفظ المشاعر؟ يسترجع ذكرى فيقول: "في ذلك اليوم، بدوت متحمسًا جدًا". ويرسم "خريطة مزاجية" شهرية: متى كنت مبدعًا؟ متى كنت متوترًا؟ وما الذي يثير شغفك؟

## 🎯 لماذا هذا مهم لـ "الرفيق"؟
لأن الذكريات ليست فقط أحداثًا، بل مشاعر. وهذا الرفيق يتذكر قلبك.

## 📊 الميزات الأساسية
| الميزة | الوصف |
| :--- | :--- |
| **حفظ المشاعر** | ربط المشاعر بالذكريات. |
| **خريطة مزاجية** | رسم بياني شهري لحالتك العاطفية. |
| **اكتشاف الشغف** | ما الموضوعات التي تثير حماسك؟ |
| **خصوصية مطلقة** | كل البيانات العاطفية محلية. |

## 💎 الصلة بنظام "الرفيق"
الذاكرة العاطفية هي "القلب". هي التي تجعل "الرفيق" يشعر بك.
