# ⌨️ Arabic Keyboard Linguistic Testing

## 📜 Executive Summary
This proposal aims to design comprehensive test cases for the Arabic virtual keyboard, ensuring it correctly handles all Arabic letters and diacritical marks.

## 🎯 Why This Matters for "The Companion"
The Arabic keyboard is the "key" that ensures the door of "The Companion" is never locked for any Arabic user. But the key must be precise. One missing letter, or a misplaced hamza, can render the experience incomplete.

## 📊 Proposed Test Cases
| Case | Description |
| :--- | :--- |
| **Basic Letters** | Test all 28 letters of the Arabic alphabet. |
| **Alef Maqsura & Yaa** | Ensure distinction between alef maqsura (ى) and yaa (ي). |
| **Hamzas** | Test hamza on alef (أ), waw (ؤ), yaa (ئ), and on the line (ء). |
| **Taa Marbuta & Maftuha** | Ensure distinction between taa marbuta (ة) and maftuha (ت). |
| **Diacritical Marks** | Test fatha (َ), damma (ُ), kasra (ِ), sukun (ْ), shadda (ّ). |
| **Ligatures** | Test laam-alef (لا), laam-alef with hamza (لأ, لإ, لآ). |

## 💎 Connection to the Ecosystem
This test is the shield that protects the "key." Without these tests, the key might be broken, and we might never know.
