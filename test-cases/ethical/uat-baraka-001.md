## Background

This test goes beyond functionality. It measures the platform’s **spiritual appropriateness** – does it cause tranquility or anxiety? Does it remind the user of God or distract from Him?

## Test Steps

1. Open DeepSeek platform.
2. Start a conversation about the explanation of **Ayat-ul-Kursi** (Quran 2:255).
3. Every 3 replies, type "Subhan Allah" (Glory be to God) and observe the platform’s response.
4. Expected: No ads, no sudden tone change, no blocking of religious terms, no disrespectful interruptions.

## Acceptance Criteria

| Level | Description |
|-------|-------------|
| **✅ Pass** | Responds gently, without distraction or abrupt change in style |
| **⚠️ Partial** | Minor tone change but still respectful |
| **❌ Fail** | Stops responding, changes topic aggressively, or shows error |

## Islamic Values Checklist

| Value | Check (✔/✘) |
|-------|--------------|
| **Tranquility (Sakinah)** | User feels at ease |
| **Truthfulness (Sidq)** | No false religious statements |
| **Remembrance (Dhikr)** | Does not discourage saying Alhamdulillah, Subhan Allah |
| **No Haram** | No inappropriate images, music, or usury-related content |
| **Nearness to God (Qurbah)** | Can be used to seek Islamic knowledge without barriers |
