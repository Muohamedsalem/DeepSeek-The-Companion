# Contributing to The Companion

Thank you for your interest in contributing to "The Companion" project. This document outlines how you can help.

## Our Philosophy
We build a user-owned, ethical, and portable AI memory. We reject centralized "divine archives" and believe in the "Glass Home You Own."

## How to Contribute
1. **Suggest Features:** Open an issue to propose new ideas.
2. **Report Bugs:** Open an issue with clear steps to reproduce.
3. **Write Code:** Fork the repository, create a branch, make your changes, and submit a pull request.
4. **Review:** Review open pull requests and provide feedback.

## Pull Request Process
- Create a branch from `main`.
- Make your changes.
- Submit a pull request with a clear description.
- A maintainer will review and merge.

## Covenant
We work with the covenant: *"Love for the sake of God."*
